# دومينز في الساحة

مسودة برنامج أنشطة دومينز في ساحة التحرير (حلب) حول الكرفان: قيمة مجتمعية كل 14 يومًا، وأنشطة تدور حولها.

## التبويبات
1. **الفكرة:** القيمة على شاشة الكرفان، ومستويات البرنامج الأربعة، والدورة في لمحة.
2. **الأنشطة:** أنشطة القيمة، والشأن العام، واليومي والدائم. تفاصيل كل نشاط في قائمة منسدلة، مع وسم «تغطية إعلامية».
3. **الرزنامة:** دورة الـ 14 يومًا، بعرضين: بطاقات (اضغط على أي يوم) أو جدول كامل.

## الملفات
- `index.html`: صفحة واحدة كاملة (الخط والشعار والصور مضمّنة، وتعمل دون إنترنت)
- `render.yaml`: إعداد النشر على Render

## النشر
- **Render:** New > Blueprint واربط المستودع.
- **GitHub Pages:** Settings > Pages > Deploy from a branch > main / root.
